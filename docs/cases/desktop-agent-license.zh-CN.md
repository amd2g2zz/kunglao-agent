# 案例 3：桌面端 agent 授权协议

> 单页脱敏实战报告。目标为商业桌面产品；披露刻意最小化 —— 不公开任何
> 还原出的密钥、参数取值或协议字段值。

## 目标

一个桌面 AI 编程 agent 的本地协议与 license 校验面：客户端证明授权
合法的那条交互。任务：刻画校验交互，并对其全部记录在案的交互离线
复现 challenge/response 计算。

## 防御面

- 校验交互外围的本地 IPC/协议定界
- 混淆的校验模块
- challenge/response 握手（服务端下发挑战，客户端计算应答）
- 校验路径周边的反篡改检测

## Agent 路线

1. 本地协议面测绘：端点、消息定界、校验流量的走向。
2. 在混淆代码中定位校验模块。
3. 抓取在线 challenge/response 交互。
4. 推导握手结构：挑战携带什么、应答必须是哪些量的函数。
5. 离线重实现应答计算。
6. 对记录交互做重放验证；任何 claim 升格前，由独立验证者盲重推
   该刻画。

## 判决

challenge/response 协议被完整刻画；应答计算对全部记录交互逐字节
复现一致。

## 证明点

跨域覆盖（桌面/协议车道）与 native、web 车道同一套机械 oracle 纪律：
刻画结论只能经独立盲验证与重放落定，不接受自我评价。
