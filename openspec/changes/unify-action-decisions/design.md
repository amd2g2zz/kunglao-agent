## Decision and results

Reuse the sampler receipt and Q-cell observation. A shared projection records the actual method, sampled method, source, and conditional weights. For host tool calls, the hook stages a signed receipt keyed by the tool call ID. It supplies an adopted method in the updated tool input without changing the host permission decision. Only the matching PostToolUse event with the same effective input publishes the Q-cell observation. The dispatch signature is captured before execution. Independent settlement always completes through the existing blind path. If execution confirmation is still outstanding, settlement seals the unbanked credit under the original dispatch ID. The matching execution callback publishes the observation and retries only the credit bank. A missing or mismatched callback leaves that credit unattributed while the verified verdict stands. A rejected or unconfirmed call leaves no pending Q-cell row. The claims ledger excludes aborted attempts from producer lookup. The evaluation executor passes its own draw through that projection. Eligibility remains a check of current authorization. Sampler support is recorded separately from dispatch authorization.

A dispatch observation describes an accepted action. Evidence and execution outcome are separate from credit. Settlement uses the dispatch identity. An interrupted trajectory may contain a completed action whose evidence awaits verification, an action whose outcome is unknown, and a proposed action without a dispatch record. The absence of a record for the last action contributes no experience. When evidence only verifies a group outcome, that evidence cannot substantiate credit for each member individually.
